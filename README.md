## Run and check the website

The website code is in this repository. Run `npm test` and `npm run build` with Node 20 or newer. Serve the generated `dist/` folder with an HTTP server. The build checks local page links and module imports, and excludes tests and repository documents from the release. GitHub Pages should publish `dist/` using a deployment workflow; building locally does not enable Pages. See FOUNDATION.md for demo-data and integration limitations.
